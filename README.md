# Living Around 🌍

**Living Around** is a sleek and responsive travel-themed website where users can explore accommodations, discover local highlights, and connect through a contact page. The platform was built using modern web technologies to provide a smooth, interactive, and mobile-friendly experience.

## Highlights ✨
- Fully responsive across all devices
- Eye-catching design
- Interactive elements throughout the site, including buttons, maps, forms, cards, and more

## Built With 🛠️
- **Bootstrap 5** for layout and responsiveness
- **JavaScript** for interactivity
- **CSS3** for custom styling
- **HTML5** for structured content

## What I Learned 📚

- Build a complete, multi-page website structure
- Create responsive layouts for different devices
- Apply Bootstrap utility classes for faster development
- Write clean, organized HTML and CSS
- Manage user interactions with JavaScript
